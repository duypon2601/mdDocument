Phân loại file và chọn phương pháp parse

File đi qua bốn chặng: API kiểm tra lúc upload, worker nhận dạng lại theo nội dung, chọn parser theo loại, rồi quyết định ảnh nào đọc bằng OCR, ảnh nào gửi Vision LLM.

Container nào làm gì

Ingestion API chỉ làm mục 1, là bước kiểm tra nhanh để từ chối file sai ngay lúc upload. Mục 2 đến 4 nặng và chạy lâu (OCR, Vision LLM) nên nằm ở Conversion Worker, scale riêng theo CPU/GPU. Các container không gọi nhau trực tiếp: workflow trong Indexing Worker xếp việc vào hàng đợi trên Temporal, Conversion Worker lấy việc từ đó, file đi qua MinIO.

1. Kiểm tra khi upload

Ingestion API

packages/api/src/ingest/api/validator.py → validate_upload(). MIME lấy từ nội dung bằng python-magic; máy không có libmagic thì đọc chữ ký đầu file. Đuôi file chỉ được tin khi nội dung là zip Office hoặc là text.

lỗi thì _sniff() theo chữ ký"] M --> Z{Zip / openxmlformats?} Z -- có --> ZO["_office_by_zip()

không tin đuôi file] ZO --> SUP TE --> SUP R --> SUP{MIME nằm trong
SUPPORTED_MIMES?} SUP -- không --> X3[415 UNSUPPORTED_FORMAT]:::err SUP -- có --> OK([Lưu MinIO, khởi chạy workflow]):::ok classDef err fill:#fee2e2,stroke:#ef4444,color:#7f1d1d classDef ok fill:#dcfce7,stroke:#22c55e,color:#14532d

SUPPORTED_MIMES: PDF, DOCX, PPTX, XLSX, HTML, text/plain, text/markdown, PNG, JPEG, TIFF, BMP, WebP.

Conversion Worker · detect_format, parse_document

4. Đọc ảnh: OCR hay Vision LLM

Conversion Worker · ocr_pages

_read_image() và vision_reason() trong activities.py, luật nhận dạng ảnh đồ họa ở parsers/image_kind.py. Chế độ đặt bằng docx_image_mode (auto / ocr / vision). Để trống vision_model là tắt Vision, khi đó mọi ảnh đi OCR.
